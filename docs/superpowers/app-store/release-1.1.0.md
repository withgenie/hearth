# Hearth 1.1.0 — 판매 전환 및 App Store 운영안

확정일: 2026-07-15
공개 상품: Mac App Store 유료 앱, 한국, 1회 구매
App Store ID: `6764480247`

## 한 줄 포지셔닝

**Claude Code·Codex용 Hearth Skill로 AI 에이전트가 프로젝트·메모·일정을 직접 움직이는 로컬 워크스페이스.**

우선순위는 AI Agent + Hearth Skill → 프로젝트·일정·메모 통합 → 로컬 저장 → 가입·구독 없는 1회 구매다. Agent 연동은 실제 `hearth` CLI와 단일 통합 Skill로 구현되어 있으며, 앱이 열려 있으면 외부 변경을 0.5~1초 안에 반영한다.

## 가격 실험

가격과 스토어 자산을 동시에 바꾸지 않는다.

| 구간 | 기간 | 가격 | 고정 조건 | 판정 목적 |
| --- | ---: | ---: | --- | --- |
| A | 14일 | ₩22,000 | 1.1.0 카피·스크린샷 | 새 자산의 효과 |
| B | 28일 | ₩11,000 | A와 같은 카피·스크린샷 | 가격 탄력성 |
| 복귀 | B 종료 즉시 | ₩22,000 | App Store Connect에 종료일 예약 | 할인 고착 방지 |

App Store Connect의 임시 가격 변경으로 B의 시작일과 종료일을 함께 예약한다. 영구 인하는 실험 결과 전까지 하지 않는다.

### 성공 기준

- 구간별 고유 노출 기기 200 이상
- 전환율 1% 이상 또는 직전 동일 기간의 2배 이상
- 유료 다운로드 3건 이상
- ₩11,000 구간의 판매량이 ₩22,000 구간보다 2배 이상일 때만 매출액 관점의 인하 효과가 있다.

### 실패 해석

- 고유 노출 200 미만: 가격보다 한국 한정 노출·외부 유입 문제
- 노출은 충분하고 상품 페이지 조회가 낮음: 아이콘·부제·첫 스크린샷 문제
- 상품 페이지 조회는 충분하고 구매 0: 가격·신뢰·체험 부재 문제
- ₩11,000에서도 구매 0: 추가 인하 대신 무료 다운로드 + Pro IAP 전환을 별도 제품 프로젝트로 검토

## 1.1.0 전환 자산 순서

1. AI 에이전트가 Hearth를 직접 움직입니다
2. 메모보드에 빠르게 기록하고 저널에서 하루를 다시 보기
3. 새 월간 캘린더에서 일정 드래그 이동
4. 날짜별 저널과 오늘 메모
5. 가입 없이, 데이터는 내 Mac에

모든 스크린샷은 실제 Hearth UI와 격리된 시드 DB를 사용한다. 제3자 앱/웹페이지가 주인공인 컷과 구현되지 않은 평가판·IAP 문구는 사용하지 않는다.
