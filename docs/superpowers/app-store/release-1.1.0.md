# Hearth 1.1.0 — 판매 전환 및 App Store 운영안

확정일: 2026-07-15
공개 상품: Mac App Store 유료 앱, 전 세계 175개 지역, 1회 구매
App Store ID: `6764480247`

## 한 줄 포지셔닝

**Claude Code·Codex용 Hearth Skill로 AI 에이전트가 프로젝트·메모·일정을 직접 움직이는 로컬 워크스페이스.**

우선순위는 AI Agent + Hearth Skill → 프로젝트·일정·메모 통합 → 로컬 저장 → 가입·구독 없는 1회 구매다. Agent 연동은 실제 `hearth` CLI와 단일 통합 Skill로 구현되어 있으며, 앱이 열려 있으면 외부 변경을 0.5~1초 안에 반영한다.

## 출시 프로모션

2026-07-15에 AI Agent + Hearth Skill 중심 ko/en 자산과 함께 전 세계 판매를 확정하고, 아래 임시 가격을 App Store Connect에 예약했다.

| 구간 | 기간 | 한국 기준 가격 | 운영 조건 | 판정 목적 |
| --- | ---: | ---: | --- | --- |
| 출시 프로모션 | 2026-07-16~2026-08-15 | ₩2,000 | ko/en 카피·스크린샷과 175개 지역 유지 | 초기 사용자 확보 |
| 정가 복귀 | 2026-08-16부터 | ₩22,000 | App Store Connect 자동 복원 | 할인 고착 방지 |

App Store Connect의 임시 가격 변경으로 시작일과 복원일을 함께 예약했다. 한국 외 지역은 Apple 가격 포인트에 따라 현지 통화로 표시된다. 프로모션 중 카피·스크린샷·가격을 추가 변경하지 않고 결과를 측정한다.

### 성공 기준

- 프로모션 기간 고유 노출 기기 200 이상
- 전환율 1% 이상 또는 직전 동일 기간의 2배 이상
- 유료 다운로드 3건 이상
- 2026-08-16 정가 복귀 뒤 같은 길이의 구간과 지역별 노출·다운로드·매출을 비교한다.

### 실패 해석

- 고유 노출 200 미만: 가격보다 외부 유입·검색 노출 문제
- 노출은 충분하고 상품 페이지 조회가 낮음: 아이콘·부제·첫 스크린샷 문제
- 상품 페이지 조회는 충분하고 구매 0: 가격·신뢰·체험 부재 문제
- ₩2,000에서도 구매 0: 추가 인하 대신 포지셔닝·유입 경로를 먼저 검토하고 무료 다운로드 + Pro IAP 전환은 별도 제품 프로젝트로 다룬다.
